# .design/

Working files for the landing-page design canvas. The canvas is published as
an Artifact; these are what it is re-seeded from, so keep them — a later pass
edits these and re-seeds rather than editing the published page.

| file | what |
|---|---|
| `gen.py` | Composes the artboards from shared pieces (the mark, the ripple field, icons, copy). Run `python3 gen.py` to regenerate every `.dc.html`. |
| `Main.dc.html` | The leading direction, desktop. |
| `MainDark.dc.html` | The same page at the dark end of `prefers-color-scheme`. |
| `Mobile.dc.html` | Main at 390. |
| `DirectionB.dc.html` | Alternate: light split hero, install as three numbered steps. |
| `DirectionC.dc.html` | Alternate: one dark deck, terminal-forward, hairline rules. |
| `canvas.json` | Artboard layout and notes. |
| `measure.py` | Renders each artboard headless and prints its real height — `canvas.json` frames are measured, not estimated. |
| `shot.py` | `python3 shot.py Main 1440 1900` screenshots one artboard to `/tmp/`. |

`measure.py` and `shot.py` use the Chromium at `/opt/pw-browsers/`. Both
caught real bugs a read-through missed: frames 500–800px too tall, a card
painting behind the hero, and a font stack whose double quotes terminated the
`style` attribute it sat in. Render before believing a layout.

The seeded canvas file itself is gitignored — it is ~2.5 MB of editor payload
regenerated by the seeding step, not source.
