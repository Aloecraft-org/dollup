dollup

Install Diluvium programs and the capabilities they run on.

Get started

# a deployment is a directory you own
dollup init
dollup source add https://dollup.aloecraft.org/std-repo/ \
    --key __DOLLUP_STD_PUBKEY__
dollup add hello

You now have the program, everything it depends on, and a lockfile recording exactly which bytes arrived. Point DRT at the directory to run it.

What you get

A deployment: one directory holding your programs, the sources they came from, and a lockfile pinning every version and hash. Copy it to another machine and you get the same thing, byte for byte — that is what makes a deployment something you can reproduce, hand to a colleague, or rebuild after a disk dies.

Everything is verified on the way in. Packages are named by the hash of their contents and listed in an index the publisher signs, so dollup can tell you that what arrived is what they published. Because a package's name is its content, the same one fetched from this mirror, a git remote, or a zipball is a single artifact — running your own mirror or an offline copy costs you a changed URL and nothing else.

Nothing executes during an install. A manifest is data and can express no behaviour, so adding a package is never running someone's setup script. What a program is then allowed to do — which files, which network, which database — stays in your config, where you can read it in one place. Installing something never grants it anything.

Verifying this repo

The repo carries a detached signature over its index, and every artifact hashes into that index — so one signature covers the repo, and it travels in the tree rather than in a transport, which is why it verifies identically over HTTPS, git, or a copy on a USB stick.

__DOLLUP_STD_PUBKEY__

Pin it in your source list, where it is an ordinary line in a file you own. A verified index means a holder of this key signed exactly these bytes — not that they are current: dollup checks authenticity, not freshness, and says so in its threat notes rather than implying more. You are trusting this page over TLS for the key's first delivery; that is the conventional bootstrap and it is worth knowing you made it.
